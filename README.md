# CV Portfolio

Персональное портфолио и резюме, созданное с использованием React и современных веб-технологий.

## Технологии

- React 18
- Vite
- React Icons
- Typography

## Функциональность

- Интерактивное портфолио
- Отображение навыков и опыта
- Контактная информация
- Адаптивный дизайн

## Установка и запуск

### Требования

- Node.js 18.x или выше
- npm или yarn

### Шаги установки

1. Клонировать репозиторий:
```bash
git clone https://github.com/katokinawa/cv.git
```

2. Перейти в директорию проекта:
```bash
cd cv
```

3. Установить зависимости:
```bash
npm install
```

4. Запустить проект в режиме разработки:
```bash
npm run dev
```

5. Для сборки production версии:
```bash
npm run build
```
